# AI CUP 2026 Homework

This repository contains the implementation for the AI CUP 2026 Rank Prediction task.

## Environment

- Python 3.10
- PyTorch 2.6.0
- CUDA 12.4
- GPU: NVIDIA GeForce RTX 4090

## Files

- `HW_rank_baseline.ipynb`  
  Main notebook for feature extraction, training, validation, and inference.

- `network.py`  
  Model architecture used for Rank Prediction.

- `utils.py`  
  Utility functions for data processing and feature extraction.
